# مدیریت کارها (Tkinter + PostgreSQL)

برنامه‌ی ساده‌ی مدیریت کارها با رابط گرافیکی Tkinter و پایگاه داده‌ی PostgreSQL، برای تمرین پایتون.

## امکانات

- افزودن، ویرایش و حذف کار
- تغییر وضعیت کار (انجام‌شده / انجام‌نشده)
- فیلتر کارها و جستجو در عنوان و توضیحات
- نمایش آمار کل کارها
- نمایش لیست کارهای حذف‌شده (حذف نرم)
- حذف کامل کار از پایگاه داده

## ساختار پروژه

| فایل | کار |
|------|-----|
| `main.py` | نقطه شروع برنامه |
| `database.py` | تمام دستورات SQL |
| `ui.py` | رابط کاربری Tkinter |

## پیش‌نیازها

- Python 3
- PostgreSQL (نصب و روشن)
- کتابخانه psycopg2:

```
python -m pip install psycopg2-binary
```

## راه‌اندازی

1. در PostgreSQL یک دیتابیس به نام `todo_db` بسازید:

```sql
CREATE DATABASE todo_db;
```

2. مشخصات اتصال را در `database.py` (متد `__init__`) تنظیم کنید:

```python
def __init__(self, host='localhost', dbname='todo_db', user='postgres', password='رمز_شما'):
```

جدول `tasks` هنگام اجرا به صورت خودکار ساخته می‌شود.

## اجرا

```
python main.py
```

## نکته‌ها

- دکمه‌ی **حذف** فقط کار را به لیست «حذف‌شده‌ها» منتقل می‌کند.
- دکمه‌ی **حذف کامل** ردیف را برای همیشه از دیتابیس پاک می‌کند و قابل بازیابی نیست.
- رمز دیتابیس را هنگام اشتراک‌گذاری کد از `database.py` پاک کنید.
